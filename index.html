IDECO AnyImage

Upload banner lên GitHub Pages, tự tạo trang Open Graph và trả về 1 link để dán lên Facebook/Zalo.

1. Kết nối GitHub

Token chỉ dùng trong phiên trình duyệt hiện tại, ứng dụng không lưu token vào localStorage.

2. Chọn banner

Chưa chọn ảnh
Khuyến nghị JPG/PNG, từ 640×320 trở lên; ảnh nhẹ sẽ tải nhanh hơn khi Facebook/Zalo quét link.

3. Nội dung chia sẻ

Link để dán vào Facebook/Zalo:
Facebook/Zalo thường lưu cache ảnh xem trước. Ứng dụng này tạo tên ảnh và link mới mỗi lần, nhờ vậy hạn chế tình trạng hiện banner cũ. Sau khi vừa tạo link, GitHub Pages đôi khi cần một khoảng ngắn để file mới xuất hiện công khai.

Cách dùng lần đầu

1) Tạo GitHub Fine-grained Personal Access Token cho repository danhmucthuoc, quyền Contents: Read and write.
2) Dán token vào ô GitHub Token và bấm Kiểm tra GitHub.
3) Chọn banner, nhập tiêu đề/mô tả rồi bấm TẠO LINK CHIA SẺ.
4) Copy link kết quả và dán link đó vào Facebook hoặc Zalo. Không upload ảnh thủ công lên bài đăng.
5) Facebook/Zalo đọc thẻ Open Graph và tự hiển thị banner; người xem bấm vào thẻ sẽ mở website đích.
